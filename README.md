## Maze Solver Guided Project
This page covers a simple python program that generates a Maze and then solves it. Currently the only factor the user can affect is the generation seed. Improvements I could/may make in the future:
- [] Control number of rows and columns of cells
- [] Implement various solving strategies (currently only uses a depth first system)
- [] Investigate optimizations that will speed up generation and reduce animation overhead
- [] Optimize and implement a stack to allow larger maze generation without stack overflow
- [] Prettier visuals and/or gameify the code

## Install
Clone repo, setup a venv, run inside venv. usual gubbins.
